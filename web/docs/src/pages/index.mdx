# Your agents should know when to stop

TALBot gives coding agents one tiny tool: send you a Telegram message when work
is ready, a decision is needed, or something is genuinely blocked. You can walk
away without leaving another dashboard open.

## Small on purpose

TALBot is a Rust CLI and a local stdio MCP server. It has no hosted account,
browser dashboard, analytics, or TALBot cloud. The notification token remains
on your machine in `~/.talbot/token`; the public docs service never receives it.

> **Keep the boundary clear.** Agents do the work, TALBot gets your attention,
> and you decide what happens next.
